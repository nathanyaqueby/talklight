# Artwork brief (for the poster artist)

The app already works without any of these files: every slot has a built-in drawing and a CSS or Lottie fallback. **Drop a file at the exact path below and it replaces the fallback automatically** (no code change, just reload). Add them one at a time; missing ones are simply skipped.

Goal: one consistent illustration family that matches the poster (flat vector, rounded shapes, people on a soft pastel circle, the cup as the recurring mascot) so the app stops looking like a generic template.

## Palette (use only these)

| Role | Colour |
|---|---|
| Brand blue / light blue | `#0F64B7` / `#64AAF2` (gradient between them only for big hero shapes) |
| Ink (outlines, hair, dark parts) | `#0B1B2B` |
| Soft tints | `#EAF3FD`, `#CFE4FA`, `#E8F2FC` |
| White / light grey | `#FFFFFF`, `#F3F7FB`, `#DCE6F0` |
| Warm accent (use sparingly) | amber `#F29900` / `#FFC94D`, coral `#D7373F` / `#FF7A6B`, only for warning / rest moments |

The official cup (`img/cup-white.svg`) may appear in any scene; please do not redraw it.

Role portraits must look like siblings (same line weight, same proportions, same background treatment). Diverse skin tones and hair are welcome; keep it friendly and gender-neutral where possible.

### SVG rules

- Always set a `viewBox`; no fixed `width` / `height`.
- Plain shapes only: no embedded raster images, no `<text>` (convert text to outlines), no filters or blur. Gradients are fine.
- Keep every file under about 30 KB. Flatten groups, merge paths, remove hidden layers and metadata (Illustrator: *Save As SVG*, "Minify", "Responsive"; Figma: export SVG with "Outline text").
- Do not rely on CSS classes or `<style>`; use attributes so the file renders the same everywhere.
- PNG is **not** wired up. If SVG is impossible, tell the developer; a PNG at 3× the shown size (e.g. 750 px for 250 px) with a transparent background is the fallback.

## Lottie files (folder `img/lottie/`)

Two files exist already (generated by `tools/build_lottie.py`: simple circles). Replace them with your own exports using **the same file names**.

| File | Where it plays | Spec |
|---|---|---|
| `breathe.json` | Guided break screen (behind the "Breathe in / out" circle) | Square, 300×300, 30 fps, exactly **300 frames (10 s) and seamlessly looping**. Inhale = first 120 frames (grow), exhale = last 180 frames (shrink). The app speeds it up to 2× for the 10 s demo break, so keep the motion calm at 1×. Drawn for the **blue gradient background**: white and very light shapes, transparent background. Leave about 15 % margin around the biggest shape. |
| `done.json` | Top of the summary sheet (plays once) | Square, 200×200, 30 fps, **no loop**, 60–90 frames. Brand blue / sky on a **light** background (e.g. badge pops, check draws, small sparkles). Must end on a clean, still final frame. |

Optional extras we can wire up later if you like: a short "alert" pulse for the watch card, and a waving cup mascot for the empty states.

### Lottie rules (Bodymovin / After Effects export)

- Export with the Bodymovin or LottieFiles plug-in as plain `.json` (not `.lottie` / dotLottie).
- Shape layers only: no expressions, no effects (blur, glow, drop shadow), no text layers (convert to shapes), no 3D layers, no embedded images, no masks with feathering.
- Trim paths, scale, position, rotation, opacity, fill / stroke and gradients are all fine.
- Transparent background (no solid layer). Under about 50 KB per file.
- The app uses the lightweight SVG player (`lottie_light`), so anything it does not support simply will not render; test in https://lottiefiles.com/preview with the "SVG" renderer.
- Users with "Reduce motion" turned on never see these; they get a still fallback.

## How to hand it over

Put the files in the paths above (or send them to the developer). Then check the page on a phone in both languages. If a slot looks wrong, it is almost always the canvas size or an opaque background that should be transparent.
